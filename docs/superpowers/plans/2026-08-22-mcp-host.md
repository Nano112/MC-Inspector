# MCP Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An embedded MCP server in a Fabric client mod so an agent can screenshot, read state/logs, inject keyboard/mouse input, drive vanilla menus, run commands and connect to servers.

**Architecture:** Stonecutter multi-version Fabric mod (`mcinspector`). A hand-rolled Streamable-HTTP JSON-RPC server (JDK `HttpServer` + Gson) dispatches `tools/call` to `Tool` objects; any game access is marshalled to the render thread via `Minecraft.execute`. Input is injected at the `KeyboardHandler`/`MouseHandler` level through `@Invoker` accessor mixins so it flows through the same path as real input (and reaches the open `Screen`).

**Tech Stack:** Kotlin 2.4.0, Fabric Loom 1.16-SNAPSHOT, Stonecutter 0.9.5, Fabric API, Fabric Language Kotlin, Gson (from MC), JUnit 5, Gradle 9.4.1.

**Spec:** `docs/superpowers/specs/2026-08-22-mcp-host-design.md`

## Global Constraints

- Versions: 1.21.8, 1.21.9, 1.21.10, 1.21.11, 26.1, 26.2; active dev version `1.21.11`; Java 21 on 1.21.x, Java 25 on 26.x.
- Group/package `dev.harrison.mcinspector`; mod id `mcinspector`.
- No MCP SDK; no new runtime deps beyond Gson (MC-provided).
- Server binds `127.0.0.1` only; default port `38271`; overrides `-Dmcinspector.port`, `config/mcinspector.json`.
- Every game-touching tool runs on the render thread with a 10 s default timeout; tool exceptions → `isError: true` text result, never a JSON-RPC error.
- Kotlin for logic, Java only for mixins. Stonecutter `//? if` markers for version splits.
- Commit after every task.

```kotlin
interface Tool {
    val name: String; val description: String
    val inputSchema: JsonObject            // JSON Schema object
    fun call(args: JsonObject): ToolResult // may throw; protocol converts to isError
}
class ToolResult(val content: List<JsonObject>, val isError: Boolean = false) {
    companion object {
        fun text(s: String): ToolResult
        fun json(o: JsonElement): ToolResult            // text block with pretty JSON
        fun image(pngBase64: String, extraText: String?): ToolResult
        fun error(msg: String): ToolResult
    }
}
class ToolRegistry { fun register(t: Tool); fun get(name): Tool?; fun all(): List<Tool> }
class McpProtocol(registry: ToolRegistry, serverName: String, serverVersion: String) {
    fun handle(body: String): String?   // null => notification (202)
}
```
