## MC-Inspector 0.1.1

Fixes clicking Inspector after Escape unexpectedly returning focus to Minecraft.

The bundled panel-lib is updated to **0.1.5**, including corrected cursor enter/leave
handling and input delivery before ImGui's hover/capture calculation. This fixes the
shared overlay for Schematio too, even when its connector bundles an older panel-lib.
CI pins the exact panel-lib source commit.

Validation: all six Minecraft builds and 318 MC-Inspector tests pass. panel-lib passes
90 tests, including three native ImGui regressions that reject the old input ordering.
A live 26.2 client with Schematio Connector 1.3.4 passed ten consecutive Escape-to-menu
cycles, alternating between Inspector and Schematio.

Download one JAR matching Minecraft 1.21.8, 1.21.9, 1.21.10, 1.21.11, 26.1 or 26.2.
Replace the previous MC-Inspector JAR and restart Minecraft. Fabric API and Fabric
Language Kotlin 1.13.12+ are required. Use Java 21+ for 1.21.x or Java 25+ for 26.x.
SHA256SUMS.txt covers all six downloads.
